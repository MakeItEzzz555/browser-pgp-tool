# Multi-Use PGP Tool

Browser-only OpenPGP key generation, encryption/signing, decryption/verification and key inspection.

## Overview

Browser-only OpenPGP key generation, encryption with optional signing, decryption/verification, and key inspection.

## Features

Generate and inspect keys, encrypt with optional signing, or decrypt and verify armored messages. Results can be downloaded, and the interface reports input/operation errors.

## Tech Stack

HTML / CSS / JavaScript / OpenPGP.js

## Getting Started

Open `index.html` in a modern browser with internet access for its OpenPGP.js 6.3.1 CDN script. The tabs provide key generation, encryption/signing, decryption/verification and key inspection. Use test keys/messages for initial exploration. User-entered key material is not included in this repository. Cryptographic round trips and interoperability were not revalidated during archival.

## Validation

Lightweight local checks: JavaScript syntax. Compilation and syntax checks do not verify application behavior. Source is preserved; interactive application behavior was not executed during archival.
